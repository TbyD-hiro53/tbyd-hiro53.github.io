# Earth / 保存棟 / SHOKO：人由来音が指摘された録音を交換する v3

2026-10-19。Earth・保存棟で「人に由来する音が混じる」と作者から不合格指摘。追加指示でSHOKOにも適用した。

今回は従来S06（ほぼ空の会議ホール451614）とS04（草地517995）を、3作品の音声取得・出典から完全に外す。旧素材の音量・EQを変えて隠す対応はしない。新たな実録2本を使用する。

## 新しい録音

1. **peqdavid5 / VentilatorRT.wav / 478643 / CC0**
   - 作者は「Channel 1は電動ファン軸上、Channel 2は離れた室内音」と説明。
   - 室内側の右チャンネルは使用せず、左の近接ファンだけを135–165秒から切り出す。
   - 開始・終了操作を避けた定常区間。0.25秒ごとのRMS CV0.056、95/5百分位比1.20。換気源そのものを主に録った素材へ変更。
   - mono、85Hz HP・1800Hz LP、目標−34dBFS。設備音を勝手に書庫の設定へ追加したとはせず、SHOKOでは室内の空気感に薄く使用する録音と出典欄へ明記。
2. **Anya_Media / Forest, close up of trees rustling in the wind.wav / 523389 / CC0**
   - 木の枝葉を近くで録音し、遠い樹冠のうねりを含む森の風。BP4025/Zoom F8。作者記載を根拠に、交通を含む候補やマイク品質不足と明記された別候補を除外。
   - 85–115秒。選択前の0.1秒RMS95/50比1.269、160Hz未満のエネルギー比8.3%。録音端や大きな過渡音を避ける。
   - stereo、160Hz HP・3600Hz LP、目標−34dBFS。

元のWAV/FLACは取得しておらず、Freesound公開HQ MP3を保存・編集した。両者とも0.20*tanhピーク整形、1秒循環重ね合わせ→29秒ループ、前後100msのエンコードガードをブラウザで除去。新しい発振器・合成ノイズ・音声除去のための生成処理は使わない。

## 人声・過渡音の検査の範囲

録音元の説明、チャンネルの役割、区間の定常性に加え、別担当がSilero VAD（閾値0.45、最低250ms）で元録音全尺を検査。検査用にRMS−24dBFSまで増幅し、風は43.2659倍、ファン左は13.7561倍。両者ともspeechCandidatesは0。

これは声の候補を機械検査した結果であり、足音・接触音・鳥・水などの不在や人による聴感合格を保証しない。実際に耳で聴いたとする報告はしていない。作者に確認してもらう新しいプレビューである。VAD・波形検査記録、出典説明、元音源hashを同梱する。

## 実装の差分

- Earth/保存棟：v2の静かな室内mix、全視点のゲイン・距離・停止/操作/UIを維持し、2層の録音とクレジットを交換。
- SHOKO：v2の7景mixを維持。室内room層の参照を新fanへ、外へつながる4景の風を新windへ交換。下層の水路2層と搬送フォーリー、音量、停止・UIはそのまま。
- 新規 `interiors-audio-v3-20261019.js`、`shoko-audio-v3-20261019.js`、`interiors-audio-v3-20261019-{fan,wind}.mp3`。
- プレビュー3HTMLのスクリプト参照だけを変更。公開版・描画アプリ・旧音版を保持。

fanはmonoとなり、Earth/保存棟のデコード量は44.1kHzで15,346,800 bytes、追加取得音声は計1,053,343 bytes。SHOKOは既存水/搬送を含み33,339,600 bytes、計2,089,489 bytes。音声操作前には音声リクエストもAudioContext生成もない。

## 検証・保存

`audio-build.json`: 区間・全フィルタ・元音源/出力hash・音量・ピーク・ループ境界。
`sources.json`: 出典・作者・ライセンス・録音説明・生素材パス。
