# Earth / 保存棟：室内の風と弱い換気音 v2

2026-10-19。Earth Origin Materialの風が室内として強く、マイクに当たるような「ボソボソ」が気になる、薄い施設ファン音も欲しいとの作者指示に対応。追加指示によりThe Preservation Hallにも同じ方針を適用。

変更は `preview/20261017/earth-origin-material.html` と `preservation-hall.html` の音スクリプト参照のみ。新規 `interiors-audio-v2-20261019.js` と `-wind.mp3` / `-fan.mp3` を使用する。公開版、承認済みv1素材、SHOKO、描画、UIデザインは変更しない。

## 音作り

- 風：既に試聴合格のwaweee / Freesound 517995「Wind in the grass」、50–80秒。原HQ MP3から取り直し、320Hzの2次ハイパスを二段、2600Hzの2次ローパス。低域の風圧成分を抑え、屋外の草擦れを遠くに残す。RMS目標−34dBFS、0.20*tanhピーク整形。
- 弱い施設ファン：既に試聴合格のkyles / Freesound 451614「room tone large convention hall vent large almost empty.flac」、285–315秒。実際のホールの換気録音を使用。前回承認した除去処理の後、85Hzハイパス・1500Hzローパス・240Hz/+2dB EQ。RMS目標−33dBFS、0.20*tanhピーク整形。新しい発振器・合成ノイズは使わない。既存の室内層を換気寄りに調整した2層構成で、同じ音源の重複再生による位相干渉を増やさない。
- いずれもCC0。元のWAV/FLACは未取得で、保存済み公開HQ MP3からの編集。メニューに出典・ライセンス・編集内容を明記。
- 1秒の循環重ね合わせで29秒ループ、前後100msをMP3エンコードガードとし、ブラウザ内デコード後に除く。既存の呼吸・星・端末等へ効果音は付けない。

## 負荷・検証

追加音声2本合計1,170,372 bytes。29秒×2層、44.1kHzステレオでデコード20,462,400 bytes（48kHzなら22,272,000 bytes）。v1から層数も取得容量も増えない。操作前には音声取得・AudioContext生成なし。メニュー隣の44pxスピーカー、初期ミュート、音量、UI表示切替、作品停止、非表示タブ、ページ離脱/復帰、別作品の音ONによる排他を維持。

`audio-build.json` に元音源/出力hash、全フィルタ、切り出し区間、音量、ピーク、ループ継ぎ目を記録。160Hz以下の風のRMSは素材段階でv1比−36.2dB。両ループの境界サンプル差が通常差分の99百分位未満であることを確認。これは風圧成分を抑えた客観的検査であり、最終的な聴感は作者のプレビュー確認対象。

ブラウザ検証記録は `results.json`。実機Safari/iPhoneではなくChromium software WebGLでの検証。独立ZIP展開・公開配信の確認は親作業で実施。
