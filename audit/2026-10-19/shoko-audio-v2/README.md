# SHOKO — 音プレビュー v2 / 2026-10-19

ユーザー指摘：水音が大きい。外につながる景では風などの環境音も欲しい。

下層の流水2層をv1の約35%（約−9.2dB）へ下げ、riverの低域通過フィルター上限を2400→1800Hz、rillを4200→2600Hzとして水音の強さを抑えた。搬送音と室内音は維持。河川の音は下層だけで流し、外皮などへ水路を持ち出さない。

外気は新しい低域を抑えた風素材を使い、外皮・受入・外光層・枝の内部へ追加。部屋の外気の入り方を音量と帯域で変える。外皮は外気を主に、受入と外光層は開口を経た距離感、枝の内部は細い採光口からの弱い気配とした。
