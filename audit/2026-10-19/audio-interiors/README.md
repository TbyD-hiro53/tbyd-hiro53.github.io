# 室内作品の環境音プレビュー — 2026-10-19

Earth Origin Material・The Preservation Hall・書庫 SHOKO の公開前試聴版。既存公開HTML/共有UI/承認済み音声を上書きせず、preview/20261017 の3ページだけに追加した。

- Earth：公開中の森林 v11、室内 v9、アプリ v10 をそのまま使用。入口は薄い室内音、記録室は外気を遠く、天体参照室はさらに静かに、開口で草を抜ける風を近くする。星・通信の効果音は付けない。
- 保存棟：現在の v7 の5視点を維持。戸の視点でだけ植生の風を近づけ、室内は小さな連続音にする。床の拍・端末に効果音を付けない。
- SHOKO：現在の v1 w2 を維持。外観は無音、入館以降は薄い室内音。下層でだけ水路2層と小さな搬送フォーリーを重ねる。紙めくり音はない。試聴開始リンクは #lower または #intake。新しいアプリの変更は既存Liquid Glassホストの参照公開、メニュー内音量/出典のキーボード操作対象への追加、プレビューのbase要素に影響されず現在のパスとクエリーを保つ視点URL更新の3点。

## 操作と負荷

メニューの左隣、44×44 px のスピーカーを1タップで切替。初期はミュート、操作するまで AudioContext 作成も音声リクエストもない。メニューには音量と出典。UI非表示・表示復帰に追従。作品の停止、タブ非表示、pagehide/pageshow、別作品の音ONに対応する。説明用の音声・合成音は追加しない。

Earth/保存棟は29秒×2層、追加転送1,170,372 bytes。SHOKOは29秒の室内音＋17秒の水路2層＋17秒の搬送、追加転送1,621,332 bytes。44.1kHzステレオでデコード時はそれぞれ20,462,400 bytes / 28,224,000 bytes。ブラウザが48kHzにデコードした場合は22,272,000 bytes / 30,720,000 bytes。画像・3Dを再描画する音処理は追加していない。

## 音源

作者が合格としたS04修正版50–80秒、S06除去版285–315秒、S07/S08/S09最初20秒の範囲を使用。公開HQ MP3由来であり、元のWAV/FLACを取得したとは表示しない。

`audio-build.json` は元音源hash・区間・処理・出力hash・音量・継ぎ目検査。`sources.json` は録音者・URL・ライセンス。水路2本は既存Confluence承認済みループをそのまま参照する。

- S04：waweee「Wind in the grass」517995、CC0。
- S06：kyles「room tone large convention hall vent large almost empty.flac」451614、CC0。
- S07：oldestmillennial「ConveyorLoop.wav」538210、CC BY 3.0。現場の大型搬送設備録音とは称さず、チェーン等によるフォーリーと明記。
- S08：Nox_Sound 479322、CC0。
- S09：peridactyloptrix 197705、CC0。

音量正規化・帯域調整・ピーク整形後、1秒の循環重ね合わせ、100msのMP3エンコードガードを付ける。ブラウザでガードを除いてループする。継ぎ目のサンプル差は通常の差分99百分位未満であることを機械確認した。作者による作品内の最終聴感確認はまだ必要。
