# Sanctum surrounding stone space: source search and three auditions

Author: the device is silent; seek a sacred-sounding stone corridor ambience. Canon describes a circular stone chamber, diameter11.2m and ceiling4.4m. No new physical layout or fictional sound-making machinery is introduced.

## Search result and distinctions

Freesound stone-room search initially returned iainmccurdy685871 “Blustery Wind In Hilltop Church”: described as wind in a small stone chapel, also old wooden door sounds. Individual page was HTTP403, so license/audio were not verified or acquired. Other results included visitors speaking in a castle, upstairs conversations, household room tone; not adopted. Cathedral-room-tone search produced unrelated music. Subsequent Freesound queries/pages returned403/429; Google/Bing/OpenAIR site were blocked by network proxy. No login conclusion is drawn from these failures and no user sign-in was requested.

Readable GitHub catalogs led to the University of York OpenAirLib project and its York Minster / MaesHowe references, but no verified downloadable room recordings with license were obtained there. The Lausanne Cathedral example lacked a visible license, so it was not reused.

The oramics/sampled Voxengo collection provides3 usable **modeled IRs**, explicitly authored with Impulse Modeler, not field recordings: St Nicolaes Church, Derlon Sanctuary, Five Columns Long. Original WAVs and license text acquired unchanged, SHA256 in acquired.json. These externally authored effects were collected from the web. They are not represented as authentic recordings of the named rooms.

## Auditions

Each IR is convolved offline with20s of the same recorded forest wind from Anya_Media523389 (CC0), via the previously processed interiors-v3 wind MP3. Match mid-sample RMS to−28dBFS; let the full residual tail finish. No voice, footsteps, singing, organ, oscillator or synthetic noise added. No new playback CPU convolution or work-scene module: this is a small separate audition page, not an installed artwork mix.

A/St Nicolaes: estimated energy-decay RT60≈3.37s, proposed first candidate for long quiet reverberance. B/Derlon≈0.85s, close-room comparison. C/FiveColumnsLong≈2.64s, intermediate. Estimates are signal measurements, not room geometry evidence or listening approval. Source WAV names are publisher labels. Stronger subjective claims about sacredness are left to author audition.
