# Sanctum — 室内音プレビュー v1 / 2026-10-19

承認済みの三条ヘリカルの造形・速度・色・密度、視点、説明本文は変更しない。今回追加するのは環を囲む室内の薄い換気音のみ。火花・光筋に雷や拍を付けず、放電や装置の機構を音で新たに説明しない。制作中のプレビューであり、作品内ミックスの作者合格・本番反映は未了。

音源は kyles, Freesound 451614, “room tone large convention hall vent large almost empty.flac”, CC0 1.0。作者が再試聴した4:45–5:15の処理区間を使用。同一の immutable `interiors-audio-v1-20261019-room.mp3` を他の室内作品と共用する。原音FLACは未取得、取得済み公開HQ MP3からの編集。出典・ライセンス・加工内容を作品の音源欄に表示する。

29秒のステレオループ。元録音区間を45Hz highpass/3500Hz lowpass、圧縮・RMS調整・softpeak処理し、1秒の循環オーバーラップを作成。前後100msの符号化ガードをデコード後に切り落とす。音量初期55%、レイヤー係数0.65、低域通過3200Hz。加工後のRMSは約−34.47dBFS。素材の生成・計測記録は ../audio-interiors/audio-build.json。

メニュー隣の44px Liquid Glassスピーカー。初期消音、操作前の音取得なし。メニュー本文の再構築後も音量と出典を再挿入。メニューを開くと既存のreading layoutに従い外側の操作を隠し、音量は内部で操作できる。閉じた後のスピーカーは1tapで切り替わる。表示されたmotionボタンの停止、非表示タブ、ページ離脱、他タブの再生に追従する。三条の位相と音響の同期は加えていない。

実装は `sanctum-audio-v1-20261019.js` と preview/20261017/sanctum.html の追加参照、同プレビューのdismiss v2化のみ。ルートの本番 sanctum.html および既存エンジンJSは変更しない。

再現に必要な固定ファイル一覧は dependencies.json。共有バイナリ・CSS・実録出典・生成条件と合わせて親作業の保存ZIPへ統合し、独立展開後に再生を再確認する。ここでZIP検査済みとは報告しない。

初回Chromium確認は、初期無音・初回操作後の29秒デコード/再生・motion停止/再開・全5視点切替を通過。その後の「メニュー中も外部スピーカーが見える」という誤ったテスト期待で停止した。共有reading layoutは意図して外側の操作を隠すため、コードを迂回させずテストを修正した。最終結果はresults.jsonに別記する。
