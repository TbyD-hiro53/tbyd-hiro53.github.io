Use the packed forest-4k.blend in the publication ZIP. Set H53_EARTH_SOURCE to its path, H53_EARTH_OUTPUT to a writable render directory and H53_SITE_ROOT to the site folder. Run Blender 4.3.2 with render-doors.py -- 3-rear and -- 0-rear; then run package-doors.py with the same key under Python with NumPy, Pillow and OIDN 1.4.3 installed. Full detail images are rendered at native size, reduced fallback images are explicitly named -small. Source forest and the existing v9 side-aperture render are unchanged.
