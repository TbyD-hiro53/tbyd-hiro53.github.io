# Coastal wind replacement — v4 preview

The author found the published v3 wind unnatural. Its source was howling through an old window, an unsuitable acoustic match for an open coast. V4 replaces that recording with Kyster's “Near the ocean.wav”, recorded among coastal dunes and scattered shrubbery near Hvide Sande, Denmark. The original includes distant sea rumble. This is a real outdoor field recording, not synthesized wind.
